plot-go — line graphs on the command line

A Go port of annacrombie/plot, drawing ASCII line charts from a stream of numbers with asciigraph doing the rendering. Pipe it a series and watch it redraw as the values arrive.

There is no /sys in a browser, so this demo follows two counters a tab really has: the gap between animation frames, and how late a zero-millisecond timeout actually fires. The processing pipeline comes from the query string — try ?p=roc:5 for rate of change, ?p=avg:5|roc:5 to smooth first, or ?p=cma for a cumulative moving average.

Source code: github.com/0magnet/plot-go. More Go and WebAssembly projects: magnetosphere.net/software.
